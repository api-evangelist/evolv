# Evolv AI

> Evolv AI (formerly Sentient Ascend) is an experience optimization and autonomous experimentation platform. Its Participant API and official client SDKs allocate visitors to experiment variants, deliver optimized configurations, and ingest behavioral events so machine learning can continuously test and personalize web and app experiences.

Generated by the API Evangelist enrichment pipeline (2026-08-13) from the Evolv APIs.json profile and repository artifacts. Evolv publishes no OpenAPI; the machine-readable contract it does publish is a Postman Collection v2, saved verbatim in this repo. Evolv's own /llms.txt does not exist — probed on evolv.ai (401), www.evolv.ai (301->401), developers.evolv.ai (404) and participants.evolv.ai (403).

## API
- [Evolv Participant API](https://developers.evolv.ai/): Runtime edge API — base https://participants.evolv.ai/v1, versioned in the path. Seven operations: GET configuration, GET/POST allocations, GET/POST/PATCH events, GET preallocations. Keyed by a public environment id in the path plus a participant uid.

## Notes for agents
- No idempotency key and no de-duplication on any write. Retrying an event double-counts a conversion.
- No rate-limit headers of any family; no Retry-After. There is no budget signal to read.
- Errors are `{"msg":"..."}` JSON with no code — except the configuration route, which returns S3 XML on 403.
- Event writes return 202 with an empty body: accepted, not confirmed. There is no event id and no read-back.
- Batch event ingestion is PATCH, not POST.
- The evolv.ai marketing site currently returns HTTP 401 (Squarespace "Private Site") on every path, so pricing, terms, privacy and support pages are unreachable anonymously. The API, docs and console are all live.

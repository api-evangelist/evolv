# Evolv AI

> Evolv AI (formerly Sentient Ascend) is an experience optimization and autonomous experimentation platform. Its Participant API and official client SDKs allocate visitors to experiment variants, deliver optimized configurations, and ingest behavioral events so machine learning can continuously test and personalize web and app experiences.

This llms.txt was generated by the API Evangelist enrichment pipeline from the Evolv APIs.json profile and repository artifacts. Evolv does not publish an OpenAPI definition; the Participant API surface below is derived from the official SDK source.

## API
- [Evolv Participant API](https://developers.evolv.ai/): Runtime edge API — base https://participants.evolv.ai/v1. GET configuration.json, GET allocations, POST data (event beacon), keyed by public environment id + participant uid.
